# Instagram SEO zones (caption & metadata)

Every item is a `book-claim` with its source.
*Phase 2 note: this gets promoted into `knowledge/visual-seo.md`.*

## Keyword "golden zones" [U.ch3]
| Zone | Tactic | Why (book's claim) |
|---|---|---|
| Name field (profile) | Profession + niche, e.g. "Name \| niche keyword" | Tells the system the account's identity [U.6], [F4.2] |
| Caption, first 5 words | Front-load the primary keyword, naturally | Categorises the post from the first moment of processing [U.ch3], [U.6] |
| Alt text | ~100-character literal scene description with keywords | Tells the system explicitly what's in the image [U.ch3], [U.6] |
| On-screen text (OCR) | Clear, readable font; include the keyword | Strengthens topic understanding [U.ch3], [F3.35] |
| Spoken audio | Say the keyword clearly in the first seconds | Speech is transcribed and used for search [U.40], [U.143], [F2.16], [F2.36] |

**Consistency rule:** if the words contradict what's shown, ranking drops [U.ch3]. The visual scene should also contain the objects the keyword names [U.ch1], [U.30], [U.154].

## Hashtags
Hashtags have been demoted; keywords matter more [U.6], [U.143], [F2.42]. **Ruling C-2:** use 0–3 specific hashtags (niche + place). Local hashtags help local discovery [F3.22].

## Caption content
- Match the caption to the video; this beats random hashtags [F2.42].
- A long, useful caption can hold the viewer past the 10-second Feed "stop" [U.28].
- Phrase so viewers save and revisit [U.105], and send to a specific person [U.36].
- Question or open prompt for conversation depth [U.60], [U.123].
- Tie the content to a real buyer need; the book says this puts it in front of shopping-minded audiences [F2.51]. Keep the CTA non-"buy now" (C-9, E-3).
- For professional audiences, a line like "share this with your team" signals business content [F2.1].

## Location
- Use a precise, real location tag (the venue, not just the city); precise tags surface on the Friends Map and in local discovery [U.27], [F3.22].
- A location in the bio/profile supports geographic circles [F4.11] (profile work: Phase 2).

## Language and dialect
- Write in the audience's dialect for a local boost [F1.37], [F3.41].
- Auto-translation exists for some languages; clear audio helps it [U.9]. On-screen text translation in Stories [F3.18].

## Tagging and cross-posting
- Tag partners, tools or brands that genuinely took part; this raises re-share odds [U.66].
- Collab posts merge audiences [U.145].
- Cross-post to Facebook and Threads via Accounts Center for a larger "signal cluster" [U.39] (book-claim).
