# Carousel rules

Each item is a `book-claim` with its source, except rows marked *editorial*, which are platform formatting choices made for this system.

## Why carousels
| Rule | Source |
|---|---|
| Carousels are the save/depth format; Reels are the reach format. Use Reels to reach new people, carousels to deepen engagement and drive purchases | [U.case lessons], [U.20], C-5 |
| Up to 20 slides; the algorithm re-shows a carousel if the user hasn't seen every slide | [U.7] |
| Posting multiple photos as a carousel beats a single image; it gets shown to the same user more than once | [F3.11] |
| A long, multi-slide post makes users stop on the Feed (the "10-second rule") | [U.28] |
| Steps, lists, before/after and comparisons are the best carousel content | [U.7], [U.case:Oysho], [U.case:Indriya] |

## Building the slides
| Rule | Source |
|---|---|
| Slide 1 must be the most attractive: a question or a promise | [U.7], [U.14] |
| Slide 2 should also work as an opener, since re-shows may start past slide 1 | *editorial*, following [U.7] |
| One idea per slide; 1–2 headlines, few words | [U.72], [U.97] |
| Keyword in big type, detail in smaller type (a typographic hierarchy) | [U.81] |
| Understood in about 1 second; no dense diagrams shrunk onto a slide | [U.41], [U.49] |
| A small detail that invites zooming ("look at step 3") adds silent engagement | [U.34], [U.148] |
| A screenshot-worthy summary slide (checklist, table or ladder) | [U.149], [H.cta] |
| A save line ("save this for…") | [U.67], [U.105] |
| A specific send line naming who benefits | [U.36], [H.10] |
| Close on one CTA: comment/DM keyword, not "link in bio" | [H.18], E-3 |
| Real facts and numbers only | E-5 |

## Format *(editorial)*
- **1080×1350 (4:5)** for full height in the Feed.
- The profile grid shows about a **3:4 crop**, which trims ~30 px from the left and right. Keep text at least 80 px from the sides.
- Use the brand's `theme_css`, with one accent colour on one key word per slide.
- Put a small slide counter (e.g. "02 / 08") in the brand label font; it supports the "come back and finish it" behaviour.

## Posting
| Rule | Source |
|---|---|
| Add music from Instagram's library when posting | [F3.11], [U.7] |
| After ~2 days, if engagement is low, reorder slides (you can now after publishing) and try a stronger slide first | [U.18], [U.7] |
| Caption keyword in the first 5 words; alt text per slide | [U.ch3], [U.6] |
| Add it to the matching highlight or series, so the profile has a browse path | [F4.10], [U.120] |
